What it does

Everything a print farm needs, nothing it doesn't

Gantry talks to each printer over your network and serves a login-protected dashboard. It never slices models and never needs a vendor's cloud.

A Queue that's safe. Queue a Plate for one Printer or any Compatible Printer. After each Job it waits until someone marks the bed clear.

Alerts where you are. Fleet-wide rules that reach ntfy, Discord, email, Telegram or the desktop, and signed webhooks.

7Drivers

Compiled in. Each printer protocol is built into the binary, so there are no plugins to install.

History, kept for good. Every Job's Outcome, filament used and its cost, and utilisation over time.

Every camera at once. A camera on every card, a grid of them all, and a timelapse of each Job. Remote viewing streams only while someone watches.

  • ViewerSees everything, changes nothing
  • OperatorControls Printers and the Queue
  • AdminPrinters, users and settings

A login, always.

TOTP and passkeys, lockouts, an audit log, and Printer credentials encrypted at rest.

  • Real control

    Pause, resume and Cancel, temperatures, lights, fans, speed, homing, jogging and filament. Bulk actions report each Printer's result.

  • A Print File library

    Upload sliced .gcode.3mf and .gcode, spin the 3D model and preview the toolpath as it prints.

  • Finds your Printers

    Bambu, Moonraker and OctoPrint Printers on the network are found and offered to an Admin, already filled in.

  • Built to connect

    A REST API with an OpenAPI document and tokens, webhooks, Prometheus metrics and Git-friendly config export.

  • Desktop apps and a wall display

    Apps for Windows, macOS and Linux that connect to a server or run one, and a full-screen view for a workshop monitor.

  • Accessible, and yours to style

    Built to WCAG 2.2 AA and checked by axe-core on every page. Light, dark or System, and six themes.

Quick start

Running in five minutes

Gantry needs a secret key (it encrypts Printer credentials) and one Admin account. There's no setup page.

Docker

openssl rand -base64 32 > gantry-secret-key   # keep it safe
docker run -d --name gantry --restart unless-stopped -p 8080:8080 -v gantry-data:/data \
  -e GANTRY_SECRET_KEY="$(cat gantry-secret-key)" {{IMAGE}}:latest
docker exec -it gantry gantry user create --admin --username admin

Binary

tar -xzf gantry-*-linux-arm64.tar.gz           # or the archive for your system
export GANTRY_SECRET_KEY="$(openssl rand -base64 32)"   # store it somewhere safe
./gantry user create --admin --username admin
./gantry serve                                   # http://127.0.0.1:8080

From source

git clone {{REPO_URL}}.git && cd gantry
pnpm install && pnpm --filter @gantry/web build
export GANTRY_SECRET_KEY="$(openssl rand -base64 32)"
cargo run -- user create --admin --username admin
cargo run                                        # http://127.0.0.1:8080

Needs Rust 1.99.1, a C/C++ compiler, and Node 26 with pnpm 12.

  1. Log in at http://<the machine>:8080 as the Admin you created.
  2. Add a Printer under Printers, or pick one Gantry found. Choose Simulated to try everything with no hardware.
  3. Reach it from anywhere through Cloudflare Tunnel or Tailscale. Never forward router ports.

How it works

A small server on your network

Browsers can't talk to printers directly, so Gantry runs beside them: a Rust server with one async task per Printer, light enough for a Raspberry Pi. The React dashboard is compiled into the binary and one SQLite file holds everything, so there's nothing else to install or run.

  • Printer ports never leave your network; only the dashboard is exposed.
  • HTTP behind any tunnel or proxy, or HTTPS on its own.
  • A personal, single-Fleet tool. No accounts with anyone else.
