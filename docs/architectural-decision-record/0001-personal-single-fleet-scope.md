# Gantry is a personal, single-Fleet tool

Gantry is built for one person or household running their own Printers: one deployment, one Fleet and a few trusted users. There is no multi-tenancy, no billing and no hosted service. We chose this over designing for a future product (PRD §14) because tenancy, isolation and a cloud relay would dominate the early work and can't be checked against a real user. Anything that turns Gantry into a product for others needs a new ADR to replace this one. It is not an incremental change.
